# RepostBot

Помощник сообщества с веб-панелью: публикации в Telegram, подключение источников VK и YouTube, ответы на сообщения, память диалогов, роли участников и учёт Twitch-чата.

**Разработка завершена. Наработки опубликованы в открытом доступе для изучения и дальнейшего развития.** Это самостоятельная нейтральная сборка 1.3.220 с пустой базой, без заранее назначенных участников и подключённых аккаунтов. Регулярные обновления и сопровождение не планируются.

## Что умеет бот

| Направление | Возможности |
| --- | --- |
| Публикации | Маршруты из Telegram, VK через API или публичную страницу, YouTube; выбор каналов назначения, шаблоны, фильтры, расписание проверки, ручная проверка, защита от повторных публикаций |
| Статистика публикаций | Журнал доставленных записей, рубрики и редактируемые жанры; подсчёт опубликованных анонсов и сравнение категорий за выбранный период |
| Ответы | Готовые ответы и FAQ, постоянные факты, триггеры, обращения и ответы на сообщения; настраиваемые провайдеры моделей, включая OpenAI, подключение ChatGPT и Ollama |
| Вложения | Контекст текста и изображений, составные обращения, чтение PDF, локальный OCR при установленных компонентах; возможности зависят от выбранной модели |
| Память и участники | История диалогов, контекст чатов, единые карточки участников, репутация, звания, фиксированные уровни и пользовательские роли |
| Связь аккаунтов | Автоматическое объединение однозначных актуальных ников Twitch/Telegram с различием в регистре или разделителях; ручное связывание по известным боту ID |
| Telegram | Основной бот и отдельный аккаунт-наблюдатель через Telethon, выбранные обсуждения, сводки, тестовые проверки; `/roll` с анимацией для обычного d6 |
| Инструменты сообщества | Настраиваемое живое общение, игровые задания, модерация, стикеры и медиа, озвучка при подключённом движке |
| Twitch | Прямой IRC или браузерный чат, журнал сообщений и наград за баллы канала, точные исключения логинов ботов, экспорт дня в JSONL/TXT |
| Управление | Подгруппы настроек, поиск, события и журнал решений, аналитика моделей, загрузка ZIP-обновлений, запуск Linux/Windows/Docker и CasaOS/ZimaOS |

Инструменты, требующие внешних аккаунтов, ключей, прав или моделей, начинают работать после настройки владельцем. Встроенных персональных сценариев и наборов стикеров в этой сборке нет; пользовательские инструкции и материалы добавляются через панель.

Готовая сборка и исходники: [релиз 1.3.220](https://github.com/MetallAngel/RepostBot/releases/tag/v1.3.220).

## Быстрый запуск

Нужен Python 3.11+; рекомендуется 3.12. Данные по умолчанию хранятся в `data/`.

**Linux:** выполните `bash start_linux.sh`. **Windows:** запустите `start_windows.bat`. Пароль панели создаётся при первом запуске и сохраняется в `data/admin-password.txt`. Откройте адрес из консоли, обычно `http://127.0.0.1:8787`.

Для воспроизводимого окружения разработки:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
# Задайте собственный ADMIN_PASSWORD длиной от 12 символов.
export ADMIN_PASSWORD='replace-with-your-own-long-password'
python -m repostbot.app
```

Браузерным парсерам нужен Chromium (`python -m playwright install chromium`) либо системный браузер. Управлению Twitch нужен системный Chrome/Chromium, Xvfb на Linux и `websocket-client`. Для OCR установите Tesseract с русским языком; для видео — FFmpeg. Dockerfile содержит эти компоненты. Google Chrome доступен на Linux amd64; на arm64 используется Chromium.

### Docker

```sh
docker compose up -d --build
```

`compose.yaml` запускает приложение и Ollama, а также скачивает указанную локальную модель. Папка проекта подключается как `/app`, данные — `./data`. Панель доступна на порту 8787. Для сервера ограничьте доступ к этому порту средствами своей сети либо используйте HTTPS-прокси.

Для CasaOS/ZimaOS есть `compose.casaos.yaml`: предварительно скопируйте файлы программы в каталог `/DATA/ChatBot` или замените путь bind mount в YAML. Временная установка дополнительных компонентов при первом запуске может занять несколько минут.

Основные переменные: `ADMIN_PASSWORD`, `WEB_HOST`, `WEB_PORT`, `DATA_DIR`, `OLLAMA_URL`, `OLLAMA_MODEL`. Ключи сервисов вводятся в своей панели и хранятся в локальной базе. Не добавляйте рабочую папку `data/`, `.env`, cookies, токены, сессии и выгруженные логи в Git.

## Первая настройка

1. В «Подключениях» укажите токен Telegram-бота и нужные источники. Предоставьте боту права в каналах назначения.
2. Создайте маршруты, проверьте шаблон и ручную отправку. Существующие записи при первой проверке по умолчанию не публикуются автоматически.
3. Настройте ответы, провайдер модели, разрешённые чаты и собственные инструкции. Игровые и инициативные функции включайте отдельно.
4. В «Участниках и ролях» используйте вкладки карточек, связи аккаунтов, званий, правок репутации и журнала.
5. Для статистики выберите канал из журнала публикаций и настройте категории в «Маршрутах».

При неоднозначном совпадении ников аккаунты автоматически не объединяются. Ручная связь доступна администратору только для уже известных системе ID. Отображаемого имени недостаточно для подтверждения личности.

## Twitch: текущие границы

В разделе аккаунта-наблюдателя выберите канал и собственный логин, подключите чат и включите учёт. Авторизация подтверждается самим транспортом; успешный HTTP-ответ проверки браузера этого не доказывает. Профиль и сессия сохраняются между перезапусками. Twitch может отклонять вход из контейнерного браузера; работоспособность зависит от его текущих правил и прав токена.

В этой версии автоматическое общение, инициатива и приветствие при запуске стрима не используются. Единственная команда — **отдельно включаемый `/roll`**, по умолчанию выключенный. Доступен также `!roll`: некоторые клиенты Twitch перехватывают неизвестные slash-команды. Пауза — 60 секунд для участника в канале.

Сообщения известных сервисных ботов исключаются из журнала и нового учёта по точному логину: Nightbot, StreamElements, Streamlabs, Moobot, Fossabot, Wizebot, Botisimo, PretzelRocks, CommanderRoot, SoundAlerts, Blerp, Sery_bot, Stay_Hydrated_Bot, AnkhBot, Deepbot, Coebot, PhantomBot, Supibot, Logviewer, PokemonCommunityGame. Можно добавить собственные исключения. По суффиксу ника ботом никто не объявляется.

Награды с пользовательским текстом распознаются по IRC-метаданным. Для наград без ввода текста нужен открытый браузерный чат: сбор идёт по видимым уведомлениям. При недоступном браузере покрытие неполное, что видно в панели. Неизвестные названия и стоимость не подменяются выдуманными данными. Загруженные старые уведомления не считаются новыми. История до подключения и события во время разрыва соединения не восстанавливаются. Награда сохраняется отдельной категорией, без автоматического запуска заданий.

### Лог для ручного анализа

«Аккаунт-наблюдатель → Twitch → Сообщения и награды»: выберите дату **в часовом поясе UTC+3** и скачайте JSONL или TXT. Скачивается весь день, независимо от страницы списка. Можно выбрать сообщения, награды или обе категории при просмотре.

Это входные данные для последующего ручного анализа или подготовки обучающего набора. Бот сам не отправляет выгрузку модели, не обучает её и не изменяет веса. Текст чата считается недоверенными данными. Учитывайте права участников при передаче своих логов внешним сервисам.

## Статистика публикаций

Бот подсчитывает опубликованные анонсы по журналу доставок и сравнивает их по настроенным рубрикам и жанрам. Отчёт можно ограничить периодом. Записи без классификации и записи с несколькими категориями учитываются отдельно. Доступность статистики зависит от накопленного журнала; полная история внешней платформы автоматически не восстанавливается.
